Database Compiler

This browser page explains the compiler workflow. The real compiler is: tools/compile-database.js

Recommended Method

  1. Install Node.js.
  2. Open Terminal / Command Prompt inside your project folder.
  3. Run: node tools/compile-database.js
  4. It creates: data/generated-resources.js
  5. Open index.html and your resource count should include compiled JSON resources.

Future Update Workflow

  1. Add new JSON files inside database/resources/ or database/assets/.
  2. Run the compiler.
  3. Upload/replace only data/generated-resources.js and any changed JSON files.
