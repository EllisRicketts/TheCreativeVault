CREATIVE VAULT V28 — DYNAMIC CATEGORIES

This update fixes the top Categories panel.

Before:
- The top Categories panel used a hard-coded list of 16 categories.
- Category buttons did not properly lead anywhere.

Now:
- Categories are generated dynamically from the live database.
- If your database has 37 categories, the panel shows all 37.
- If you add more later, the panel updates automatically.
- Category cards show resource counts.
- Clicking a category closes the panel, searches/filters that category, and scrolls to results.

Also updated:
- Applications now pulls top companies from the database.
- Collections counts matching resources.
- Recently Added pulls from dateAdded/lastReviewed metadata.
